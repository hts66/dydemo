# 视频模块详细需求

## 1. 模块目标

提供短视频内容的生产与消费闭环：用户可上传/删除作品，观众以全屏竖滑方式沉浸式浏览推荐、热门、关注、好友四类内容流，并支持搜索与观看历史。要求播放流畅、滑动不错位、翻页加载无感。

## 2. 功能需求

### 2.1 内容流

| 内容流 | 入口 | 数据规则 |
| --- | --- | --- |
| 推荐流 | 推荐页（全屏竖滑） | 随机推荐（`random=true` + seed 分页），保证翻页不重复 |
| 热门流 | 精选页 | 按热度（播放/点赞/评论综合）排序 |
| 关注流 | 关注页 | 仅当前用户关注者发布的作品，需登录 |
| 好友流 | 好友页 | 仅双向关注（好友）的作品，userId 只取自 token，防越权 |

- 分页统一采用 `page + size`，排序稳定（`ORDER BY created_at DESC, id DESC`）。
- 列表项携带作者信息（用户名、头像）与当前用户的点赞状态。

### 2.2 播放器与交互

- 基于 Video.js；竖滑切换上/下一个视频，滑到即自动播放、滑走暂停。
- 容器高度 100% 动态计算（不用固定 100vh），CSS 与 JS offset 同步，保证竖滑全程全屏、不出现半屏视频。
- 支持点击暂停/播放、进度条、封面图占位；视频懒加载与预加载相邻视频。
- 作品详情弹窗：标题、描述、作者、点赞数、评论入口。

### 2.3 作品发布

- 支持视频与图片两种类型。
- 上传素材：视频文件、封面图、标题（≤99 字符）、描述。
- 上传流程：前端先调上传接口拿到文件 URL（视频、图片分开传），再调发布接口落库；发布前放弃时可对未使用文件调 cleanup 清理。
- 文件存储：配置了 MinIO 则存 MinIO（bucket `dydemo`，videos/images 目录），否则存本地磁盘；可通过 FFmpeg 处理视频。

### 2.4 作品管理

- 作者可删除自己的作品（校验作品归属）。
- 用户作品分页：`GET /api/works/user/{userId}`。

### 2.5 搜索

- 按关键词匹配标题/描述（MySQL LIKE），分页返回。
- 同时作为 AI 语义推荐失败时的兜底通道。

### 2.6 观看历史

- 播放时上报：user_id、work_id、watch_duration（观看时长）、is_complete（是否完播）。
- 用于未来个性化推荐与"继续观看"。

## 3. 业务规则

- 公开浏览接口放行；发布、删除、关注流/好友流、历史上报需要登录。
- 只能删除本人作品。
- 删除作品时关联的点赞、评论、向量数据需考虑一致性（当前为业务层处理）。
- 作品统计字段：点赞数、评论数、播放数由互动行为维护。

## 4. 接口清单

| 方法 | 路径 | 说明 | 鉴权 |
| --- | --- | --- | --- |
| GET | `/api/works?page&size&keyword&random&seed` | 作品列表/搜索/随机推荐 | 放行 |
| GET | `/api/works/{id}` | 作品详情 | 放行 |
| GET | `/api/works/user/{userId}` | 某用户的作品 | 放行 |
| GET | `/api/works/hot` | 热门作品分页 | 放行 |
| GET | `/api/works/recommend` | AI/推荐作品 | 放行 |
| GET | `/api/works/my/following` | 关注流 | 鉴权 |
| GET | `/api/works/my/friends` | 好友流 | 鉴权 |
| POST | `/api/works` | 发布作品 | 鉴权 |
| DELETE | `/api/works/{id}` | 删除作品（仅作者） | 鉴权 |
| POST | `/api/works/watch` | 上报观看历史 | 鉴权 |
| POST | `/api/works/seed` | 内部造数据接口 | — |
| POST | `/api/upload/video` `/image` `/avatar` `/background` `/file` | 文件上传，返回 URL | 按用途 |
| POST | `/api/upload/cleanup` | 清理未使用的上传文件 | — |

## 5. 数据与存储

- MySQL `works` 表：类型、URL、封面、标题、描述、作者、点赞/评论/播放计数。
- MySQL `watch_history` 表：user_id、work_id、watch_duration、is_complete。
- MinIO/本地磁盘：视频与图片文件。

## 6. 前端页面与组件

- 页面：Recommend（推荐）、Featured（精选/热门）、Following（关注）、Friends（好友）、Profile/My（主页作品）、Search、UploadVideo。
- 核心组件：`BaseVideo.vue`、`SlideVerticalInfinite.vue`（竖滑无限流）、`SlideList.vue`、`VideoPlayerModal.vue`、`VideoDetailModal.vue`。

## 7. 完成状态与后续规划

- **已完成**：四类内容流、全屏竖滑播放、上传发布删除、搜索、观看历史、预加载；压测覆盖列表与视频下载场景。
- **待优化**：
  - **新作品发布后自动触发 AI 向量化**（当前需手动执行 `/api/vector/process-all`，新视频对 AI 助手不可见）；
  - 删除作品时同步删除 Qdrant 向量点；
  - 视频转码/多清晰度、CDN 分发；
  - 基于观看历史的个性化推荐流；
  - 上传大小/时长/格式的前后端强校验与进度展示。
